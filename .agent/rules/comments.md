# Comment Rules

## Always

- Keep comments simple, concise and direct.
- Finish comments with a period.
- If possible leave references to docs, tickets, or other relevant information that can help understand the context of the comment.

## Never

- NEVER write comments that are redundant, obvious, or do not add value to the code.
- NEVER leave todo’s, placeholders or missing pieces, unless they are not in scope of the current task and are properly documented in the code or in a comment.
