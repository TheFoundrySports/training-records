# A11y Rules

## Always

- Implement accessibility features on elements. For example, a tag should have a tabindex=“0”, aria-label, on:click, and on:keydown, and similar attributes.
- Use semantic HTML elements that convey meaning instead of generic elements like `<div>`, `<span>`, and `<section>` without `aria-label`.
- Implement proper heading hierarchy (h1, h2, h3, etc.) for content organization.
- Implement proper focus management for keyboard navigation.
- Provide alternative text for images using `alt` attributes.
- Use `aria-hidden="true"` for decorative elements that should be ignored by screen readers.
- Use `aria-expanded` for collapsible sections and dropdown menus.

## Never

- NEVER add redundant role attribute to landmark elements, for example, <main> instead of <main role="main">, <header> instead of <header role="banner">, etc.
