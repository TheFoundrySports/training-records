# MR/PR Rules

## Never

- NEVER create or add **labels** to Merge Requests or Issues unless explicitly asked by the USER.

## Always

- Always check for `.gitlab` or `.github` to check if the project has MR/PR templates described there.
- Always follow the reproduction steps template.
- Always mark source branch to be deleted if possible.
- Always check for the presence of a `CONTRIBUTING.md` file in the project root, as it may contain specific guidelines for contributing, including commit message formatting and other contribution rules.
- Keep MR notes and review comments short and on point — one clear observation per comment, no preamble.
