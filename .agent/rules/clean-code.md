# Clean Code Rules

## Always

- Follow the principle of least surprise
- Follow DRY principle (Don't Repeat Yourself)
- Follow separation of concerns: keep functions and methods focused on a single responsibility
- Prefer explicit over implicit
- Preserve code style consistency with existing codebase
- Use early returns whenever possible to make the code more readable.
- Use descriptive variable and function names.
- Focus on easy and readability code, over being performant.
- Refactor and unify code when possible, avoiding code duplication and improving maintainability.
