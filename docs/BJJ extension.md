BJJ extension

## Goal

As a athlete I want to record my Brasilian JiuJitsu (from now BJJ) workouts. As we don't have a clear view of all different technics , the athlete
will provide a good description of all technics applied in a class and the system will use AI to adjust and determine the "correct" technics.

## Requisites

* Search all official technics to have a register with all of them and also a good description and a youtube video
* The workout will be stored in section (1, 2, 3), each section will have a goal, for example, invert the position, finalize or any other described by the athlete.
* to achieve the goal the atlhet will have to execute multiples technics. 
* The athlete will describe each section and the AI will suggest a better description of it based on technics the system has. 
* let's create a 2 steops form, so the user will decide if create a BJJ or Crossfit Workout
* Depending on the selection decide which form load.
* The user will be able to add multiples Section to describe the workout and it will be stored 
* The AI will generate a new text for each section that will also be store and will have the best description.
* The AI generated text will use always the technics if they are stored and will find new ones if it is not.
